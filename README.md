# URL Shortener API

A REST API that shortens URLs, built to demonstrate core software
engineering fundamentals: algorithm design, OOP interfaces, a
relational data layer, automated testing, CI, and containerization.

## What it does

```
POST /shorten   { "url": "https://example.com/some/long/path" }
                -> { "short_code": "0001", "original_url": "..." }

GET /0001       -> 307 redirect to the original URL

GET /health     -> { "status": "ok", "stored_urls": 1 }
```

## Design

**Algorithm.** Short codes are generated with base62 encoding
(digits + lowercase + uppercase) of an incrementing counter. Base62
keeps every character URL-safe with no escaping, and encoding runs in
O(log62 n) time, which is effectively constant for any realistic
counter size.

**OOP design.** `storage.py` defines an abstract `URLStorage`
interface with two interchangeable implementations:
`InMemoryStorage` (a plain hash map, useful for tests) and
`SQLiteStorage` (a real relational backend). The service layer in
`shortener.py` depends only on the abstract interface, so swapping in
a different backend (Postgres, DynamoDB) means writing one new class,
not touching any existing logic. This is the interface-based design
Amazon's SDE role description calls out directly.

**Data structures.** Both storage backends resolve short codes in
O(1) average time: the in-memory version via a Python dict, the
SQLite version via a primary-key index.

**Testing.** 10 unit tests cover the encoding algorithm's
correctness (round-trip encode/decode) and the service layer's
behavior across both storage backends, proving the abstraction
actually holds.

**CI/CD.** `.github/workflows/ci.yml` runs the full test suite on
every push and pull request via GitHub Actions.

**Containerization.** The included `Dockerfile` packages the API into
a container, the standard first step toward deploying on any
cloud-native platform (ECS, EKS, or Lambda via a container image on
AWS).

## Running locally

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Then visit `http://localhost:8000/docs` for interactive API docs
(auto-generated by FastAPI).

## Running with Docker

```bash
docker build -t url-shortener .
docker run -p 8000:8000 url-shortener
```

## Running tests

```bash
pytest tests/ -v
```

## How this was built

I used Claude to scaffold this project, generate the initial
implementation, and catch a routing bug (see the comment above the
`/{short_code}` route in `main.py`). I reviewed, tested, and
understand every design decision below, and I can walk through the
algorithm, the storage abstraction, and the bug fix in detail.

## Possible extensions

- Swap SQLite for Postgres or DynamoDB by adding one new class that
  implements `URLStorage`, no other file needs to change
- Add rate limiting per client
- Add click analytics per short code
- Deploy the container to AWS ECS or Lambda
